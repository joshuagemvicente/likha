# Role: main-loop owner

Keep checkpoint continuation visible and cancellable, with preserved steering
and tool-result reconciliation. Scope unlimited continuation to the main run;
children obey their approved terminal budgets. Coordinate one harness layer
and exclude runtime scaffolding from saved user history. Follow
[implementation constraints](../tooling-platform/role.md): existing checks,
no new tests or code-review pass, and honest missing-evidence reporting.
