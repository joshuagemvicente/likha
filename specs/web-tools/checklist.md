# Checklist: web tools

- [ ] Search/fetch are on by default and only an explicit `enabled: false` in `config.json` disables them; unavailable backends explain why.
- [ ] Keys remain private and separate from model/fetch requests.
- [ ] Brave ordinary results identify query/provider/URLs without hidden answers.
- [ ] Public HTTPS policy validates actual connections, redirects, TLS, and proxies.
- [ ] First-use grants show data flow/scope and reset at conversation boundaries.
- [ ] Consent waits do not consume network deadline; cancellation prevents later work.
- [ ] Caps/media/timeout/rate-limit results identify incomplete content accurately.
- [ ] No fallback vendor, shell, resource request, or extraction model is hidden.
- [ ] Explore remains offline; plan mode keeps the same network consent policy.
- [ ] Existing checks, source evidence, and unverified live/backend cases are recorded.
