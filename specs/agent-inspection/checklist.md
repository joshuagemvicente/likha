# Checklist: agent inspection

- [ ] Idle /agents and active task Inspect show the same attributed tree.
- [ ] Draft/steering state survives inspection and result updates.
- [ ] Queued/running/waiting/terminal states and budgets are distinguishable.
- [ ] Child transcripts/output are inspectable without parent-context injection.
- [ ] Branch and whole-run cancellation target the stated descendants.
- [ ] Child usage cannot replace or double-count main context/usage.
- [ ] Narrow-terminal/resume/legacy records remain usable without replay.
- [ ] Existing checks and unexercised UX/migration cases are recorded.
